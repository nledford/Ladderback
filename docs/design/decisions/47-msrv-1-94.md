# Decision 47: MSRV 1.94

**The minimum supported Rust version is 1.94, set once as the workspace's `rust-version` and inherited by every crate** (recorded 2026-11-11). It was 1.91, the floor `rustic_core` 0.13 and `rustic_backend` 0.7 set through OpenDAL. `sqlx` 0.9 needs 1.94, and the store stays on 0.8 only until #174 moves it. Ladderback ships binaries (§12), so the MSRV binds only those who build it from source, and 1.94 shipped in March 2026.

CI builds with the stable channel `rust-toolchain.toml` names, not with the MSRV, so no check holds the floor between bumps: a raise is proven by building the workspace (host crates with `--all-targets`, and `web` for wasm32) with that toolchain when it is made. The host build runs on Linux, in the `rust:<version>` image with `RUSTUP_TOOLCHAIN=<version>`, because `rust-toolchain.toml` otherwise wins over the image's compiler; macOS 27 can't load the proc-macro libraries 1.94 builds, so a Mac proves only the wasm32 build. 1.94.0 passed both on 2026-11-11. A dependency that needs a newer compiler raises the MSRV in its own change, recorded here.
