# Decisions

Each file here holds one decision of §16 of the design, named `NN-<slug>.md` after its number and a short form of its question, with the question as its heading and the decision as its text. To add one, take the next free number, write a file named as above and add its row to the index in [roadmap.md §16](../roadmap.md#16-decisions); a number is taken only at the final rebase, and the branch that merges second renumbers (§13.5, and the parallel-agents rule in [AGENTS.md](../../../AGENTS.md)).
