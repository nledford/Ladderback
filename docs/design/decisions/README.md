# Decisions

Each file here holds one decision of §16 of the design, named `NN-<slug>.md` after its number and a short form of its question, with `# Decision NN: <question>` as its heading and the decision as its text. To add one, take the next free number, write a file named as above and run `just decision-index`, which writes the index in [roadmap.md §16](../roadmap.md#16-decisions) from the files' numbers and headings (a decision a later one replaced says so in a paragraph starting `**Superseded by decision NN**`, and its row says so too); a number is taken only at the final rebase, and the branch that merges second renumbers (§13.5, and the parallel-agents rule in [AGENTS.md](../../../AGENTS.md)).

A decision is history and keeps the words of its date: one recorded before 2026-11-14 can name the milestones after M3 by their old names, which [roadmap.md §14](../roadmap.md#14-milestones) maps to today's ("Old names").
