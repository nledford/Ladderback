# Decision 62: Another agent's recent snapshots come from another machine

**A snapshot another agent tagged in the last 30 days, or dated later, comes from another host, whatever host it records** (recorded 2026-11-11, §7.3; #214). A repository this agent maintains warns of other hosts (`maintenance-other-hosts`, §7.3) when it holds such a snapshot, as it does of one whose host is none of this agent's. One another agent tagged longer ago than that is judged by its host alone, as before.

Why:

- **Two machines can share one host name.** Two `raspberrypi`, each running its own agent and each maintaining one repository locally, record the same host, and the host alone can't tell their snapshots apart: neither was warned that a second maintainer exists (I1). Their agent IDs differ, unless one machine was cloned with the other's data folder (below), and every Ladderback backup carries its agent's (decision 8).
- **Only recent ones, so a reinstalled machine stops warning by itself.** A machine reinstalled, or given a new configuration folder, runs a new agent with a new ID, and its old snapshots carry the old one under the same host name. Counted forever, they would warn forever, with no way to say "that was me". A second maintainer that keeps backing up to the repository keeps warning; an old ID that makes no more snapshots warns until its newest is 30 days old. Adopting that history into a plan of this agent (§7.3) rewrites it under this agent's tags: the adoption, and its preview, still warn of it, since they see it before the rewrite, and nothing after them does. A snapshot of the old ID with no plan tag can't be adopted, and warns its 30 days out.
- **30 days, inclusive, from the `Clock` port's now.** A snapshot exactly 30 days old still counts; one a moment older doesn't. One dated after now, by a clock ahead of this machine's, counts, until now passes it. The span is the constant `OTHER_AGENT_RECENCY` in `domain`, not a setting: a reinstall is rare, and a month is long enough for a machine that backs up weekly to be seen, short enough that the warning of an old ID doesn't become noise people learn to ignore.
- **The host name alone still decides for the rest.** A snapshot no agent tagged (plain rustic's), or another agent's older than 30 days, is another host's only when its host is none this agent records, as #189 decided. So an old snapshot another agent made under another host's name still warns, and a machine that was renamed and reinstalled still names its old host in its configuration to quiet it. This agent's own snapshots are this host's under any name.
- **The warning names the host the snapshot records,** even when that is this machine's own name, and its text is unchanged: "This repository holds snapshots from another host, raspberrypi" read on a machine called `raspberrypi` says exactly what to check. It counts host names, not machines: two other `raspberrypi` count as one.
- **What it still can't see.** A second maintainer under this machine's name that backs up nothing to the repository for 30 days (its plan moved elsewhere, a monthly or manual plan) but keeps maintaining it; one whose clock runs more than 30 days behind this one's, or this one's ahead; and a machine cloned with its data folder, which carries this agent's own ID and so is this host. Each is a second maintainer the hub of M4 sees and this rule doesn't.

Alternatives: counting another agent's snapshots of any age (a reinstalled machine warns forever); judging them recent against this agent's own oldest snapshot in the repository rather than against now (it would keep warning of a second maintainer that stopped backing up there, and needs no clock, but a machine that backs up nothing to a repository it maintains has nothing to compare with, and how long a warning lasts would follow each plan's retention); a "this was me" action that retires an old agent ID (state to store and a UI to build, for what the hub of M4 will settle anyway, since it knows every agent); and leaving #214 to the hub (two standalone maintainers stay silent until then).
