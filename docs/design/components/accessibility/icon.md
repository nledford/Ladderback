# The icon

- **The icon** is `Icon` (`components/icon.rs`), a thirteenth component: one Lucide glyph from `lepticons-data` (`LucideGlyph`, a signal, so the drawing can follow a state), its shapes the crate's own markup inside an `<svg>` root of the icon's own, stroked in `currentColor`. The status badge draws with it (decision 103). It is never a tab stop (`focusable="false"`).

  What a screen reader meets is `components/icon/rules.rs`, decided on the host. `Meaning::Decorative`, the default, is `aria-hidden`: decoration beside words that say what it shows, or inside a control its own label names. `Meaning::Labeled(label)` is an image (`role="img"`) named by the label (`aria-label`), for an icon that says something no words beside it say. A meaningful icon can't be made without a label, but the type can't stop an empty one, which leaves an image without a name (1.1.1): the caller's duty, as a spinner's label is.

  It takes its `tone` and `size` from the shared vocabulary and leaves none out. Its default tone is `Inherit`, not `Primary`: an icon beside words or inside a control takes their color, so their contrast pairs cover it, and it never draws the eye away from them. Its default size is `Small` (`rules::default_size`), as tall as the text, and every size draws at the shared scale's length, so an icon and a spinner of one size line up; the root's own `width` and `height` of 1em keep it the text's height without the stylesheet. In a line of text it is centered on the text as an inline image is. It has no placement: it is inline by nature, and no use yet needs a line of its own (a placement waits for one). Under forced colors it follows the vocabulary's rule, the text's own color whatever the tone.

  Its look is Tailwind utilities (decision 117), logical ones only, and no rule of its own in `style.css` (#931): `rules::icon_class` returns the icon's own class, its tone's and its size's, which set `--tone` and `--size`, and the utilities that draw with them (`text-(--tone)`, `inline-(--size)`, `block-(--size)`), with `align-middle` and `flex-none`. The `icon` class stays as its name, which an outside link's utilities use to space its icon from its words.

  The caller's duties under WCAG 2.2 AA, which the component can't meet for it:

  - **A label on every meaningful icon,** saying what it shows (1.1.1).
  - **A labeled icon whose glyph changes is built anew with the new glyph's label.** The glyph is a signal and the label is fixed when the icon is built, so an icon that only swapped its glyph would keep naming what it no longer shows (1.1.1). A decorative icon has no name to go stale, so its glyph may follow a state in place, as the status badge's and the toggle's do.
  - **Never a tone alone (1.4.1, A2).** A tone tints the glyph; its shape or the words beside it carry the meaning.
  - **An icon-only control is named on the control** (`aria-label` on the button), and the icon inside stays decoration, so a screen reader hears the control's name once and no image inside it. A toggle keeps one name, its state in `aria-pressed` and, for a sighted reader, in the glyph.
  - **Direction.** No glyph is mirrored in a right-to-left page: Lucide draws a clock or a bell the same either way, and a glyph whose meaning follows the reading direction (an arrow to the next page) needs its caller to pick the glyph for the page's direction.

  Not taken from MUI's `SvgIcon`, the reference: arbitrary colors (`sx`, `htmlColor`), font icons, its "action" and "disabled" colors and a stroke width that ignores the size; each would be a color or a length outside the vocabulary. The gallery's "Icon" demo uses only glyphs from the `lepticons-data` categories the status badge already enables, so it adds no category to the wasm (§8.1). It shows the default before a line of words, every size as a named image, every tone named in words beside its icon, and an icon-only toggle button, **Demo notifications**, its bell crossed out while it is off; `features/ui/components/icon.feature` checks the semantics, the color, height and centering in a line of text, the button's name, state and glyph, the sizes at 200 % text against the spinner's, each tone's color and forced colors.
