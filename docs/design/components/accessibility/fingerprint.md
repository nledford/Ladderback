# The fingerprint

- **The fingerprint** is `Fingerprint` (`components/fingerprint.rs`), for a key's fingerprint as a person compares it with another screen ([decision 121, "The fingerprint"](../../decisions/121-pairing-a-machine-with-its-hub.md#the-fingerprint)): the hub key's in the pairing-token dialog, later the agent key's on a pending row. It is shown in full, never cut short, in monospace, in its groups of four. Its caller passes the fingerprint (`7K3Q-M9XD-2RTV-8HFA-QW5N`) and its name ("Hub key fingerprint"); `rules::groups` (`components/fingerprint/rules.rs`), tested on the host, groups its characters in fours, every one kept and the hyphens dropped.

  A screen reader is given a `role="group"` named by the caller (`aria-label`), then one `role="img"` per character whose `aria-label` is that character alone, so it is spoken a character at a time and never as a word; the hyphens between groups are `aria-hidden`. Nothing in it is a tab stop. Its text stays selectable, and a copy is the plain string, hyphens and all. Each group is `inline-block` and `whitespace-nowrap`, so at 320 CSS px with 200 % text the fingerprint wraps between groups and never inside one (1.4.10). It is laid out left to right (`dir="ltr"`) in every locale, since its characters keep their order. It has no tone, size or placement: it takes the text's size and color and stands in its line.

  The gallery's "Fingerprint" demo shows one, labeled by visible words; `features/ui/components/fingerprint.feature` checks what a screen reader is given and that Tab never stops in it, the copy, and the wrap at 320 px with 200 % text.
