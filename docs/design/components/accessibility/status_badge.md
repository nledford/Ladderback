  - `StatusBadge` (visible text on a colored pill, never color alone, after the state's own Lucide icon; §16, decision 103), a `Badge` (below) in its state's tone. `BadgeState` (`status_badge/rules.rs`) maps each state to its badge's tone and its icon and is host-tested: a run that ended in its status tone's pair (Succeeded in Success's, Succeeded with warnings in Warning's, a success with something to read that never shows as a clean run's green (#942), Failed in Error's), the other states in the badge's own Loading and Empty pairs (`Primary` and `Secondary`).
    - *Checked.* The gallery shows all seven states, and `features/ui/components/status_badge.feature` checks each icon in Chromium, that no badge moves, that the icon is as tall as its text at 200% text size and that Succeeded, Succeeded with warnings and Failed are each drawn in their pair in light and dark colors; `features/ui/operations.feature` checks that a live row's icon follows its run as it ends, and that a run that succeeded with warnings shows in the Warning tone, with the warning icon.
    - *Icons.* The maintainer's (#384): `clock` for queued, `loader-circle` for running, `circle-check` for succeeded, `triangle-alert` for succeeded with warnings (Lucide's `triangle-exclamation-point` under its earlier name, the one the `lepticons-data` release has), `circle-x` for failed, `circle-slash` for cancelled and `circle-dashed` for no result.
    - *Decoration.* The icon is an `Icon` (below) in its defaults: `aria-hidden="true"` and `focusable="false"`, so a screen reader reads the label once, stroked in the text's color (the `Inherit` tone), so the badge and status pairs of the contrast gate cover it, and `1em` tall (the `Small` size), so it grows with the text.
    - *Still.* It never moves, the running one either: an operation can run for hours while the page is in use, nothing on the page could stop a spinner (WCAG 2.2.2, Pause, Stop, Hide), and the label already says it runs.
