- **The tree** is `Tree` (`components/tree.rs`), an eleventh component, for a snapshot's tree (§4.4): one flat `<ul role="tree">` named by its `aria-label`, each row an `<li role="treeitem">` named by its entry's name and described by what the entry is, indented by its level from the start of the line. What it shows and does is `rules::Tree` (`components/tree/rules.rs`), decided on the host: the rows, which one holds the tab stop (that row is also `aria-selected`), each key's move, the type-ahead (the letters typed within 500 ms, at most 64), which folder to read next and what an answer changes. A folder's children are read through the `FolderLoader` the page passes, a page at a time; an answer for a folder closed or read since is dropped.

  A folder with more to read ends in a row that reads the next page (its position one past the shown entries, its set size the folder's total); a refusal shows in a `role="alert"` paragraph under the tree, closing a folder whose first page it refused and keeping the entries of one already shown. The gallery's "Tree" demo has a folder of two files, an empty one, one read in pages of two, one never answered and one refused, a link, a pipe and a file; `features/ui/components/tree.feature` drives it by keyboard alone, right to left too.
